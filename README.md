# Практичні роботи 10–12 (Варіант 1): Збір та аналіз веб-даних

Програма на мові Python для автоматичного збору, очищення, аналізу та візуалізації цитат із вебсторінок `https://quotes.toscrape.com/page/{}/`. Реалізована з використанням ООП (`WebScraper` та `DataProcessor`), перевірки коректності вводу користувача, обробки винятків (`try-except`) і збереження результатів у кілька форматів.

## Основні можливості

- Інтерактивний запит кількості сторінок для парсингу (від `1` до `5`) із перехопленням некоректного вводу.
- Надсилання HTTP GET-запитів через `requests` із заголовком `User-Agent`, таймаутом та обробкою мережевих/HTTP помилок.
- Розбір HTML-документів за допомогою `BeautifulSoup` (`bs4`) та очищення тексту цитат від лапок і зайвих пробілів.
- Статистичний аналіз у `pandas` (загальна кількість цитат, кількість унікальних авторів, середня кількість тегів, ТОП-5 авторів).
- Побудова стовпчастої діаграми ТОП-5 авторів у `matplotlib` та експорт даних у CSV, JSON і PNG.

## Використані бібліотеки

- `requests`
- `beautifulsoup4` (`bs4`)
- `pandas`
- `matplotlib`
- Вбудовані модулі стандартної бібліотеки Python: `csv`, `json`, `os`
